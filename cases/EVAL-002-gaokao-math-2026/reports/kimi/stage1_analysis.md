## 4.4 难度梯度变化

三年试卷的难度梯度结构高度一致，呈现以下特征：

（1）选择题：第1-7题为基础题，第8-10题为中等难度题。整体难度梯度平稳。

（2）填空题：第11-13题为基础题，第14-15题为中等偏难题（常设置多结论判断或双空）。

（3）解答题：第16-18题为中等难度（13-14分），第19-20题为较难题（15分），第21题为最难（新定义题型）。

（4）整体难度：三年试卷整体难度相当，均遵循“易:中:难约4:4:2”的比例分布，符合高考选拔性考试的要求。

| 2025年 | 第14题 | 3D打印机零件 | 以多面体为载体考查体积计算 |

## 5.2 设问方式创新

三年真题在设问方式上的创新主要体现在以下方面：

（1）开放性设问：2023年和2025年的解答题第16或17题引入"选择条件"的开放性设问方式，考生可从多个条件中选择其一作答，增加了试卷的灵活性。

（2）多结论判断：2022年、2023年、2025年的填空题第15题均设置多结论判断题型，要求考生判断多个命题的正确性，考查综合思维能力。

（3）双空设计：2022年第14题设置双空（取值+最值），增加了填空题的区分度。

（4）开放答案：2025年第13题要求写出满足条件的一组值，答案不唯一，体现了开放性命题趋势。

## 5.3 知识交汇创新

三年真题注重不同知识模块的交叉融合，主要体现在：

（1）数列与充要条件：2022年第6题将等差数列与充要条件结合考查。

（2）函数与充要条件：2023年第8题和2025年第7题将函数性质与充要条件结合。

（3）数列综合：2023年第14题和2025年第5题将等差数列与等比数列综合考查。

（4）数列与不等式：2022年第15题数列递推中融入不等式判断。

## 5.4 新定义题型演变

解答题第21题连续三年采用新定义题型，但定义类型有所演变：

|  |  |  |  |  |
|:--:|:--:|:--:|:--:|:--:|
| **年份** | **新定义名称** | **类型** | **定义描述** | **涉及知识** |
| 2022年 | m-连续可表数列 | 数列新定义 | 定义数列的连续子列和能表示1到m的所有整数 | 数列、组合 |
| 2023年 | r_n数列 | 数列新定义 | 基于前n项和定义新的数列指标 | 数列、不等式 |
| 2025年 | k列 | 组合新定义 | 定义在网格上的特定路径序列 | 组合、数论 |

新定义题型的演变趋势：从纯数列定义逐步向组合、数论方向扩展，题目综合性增强，对考生的抽象思维和即时学习能力要求更高。

# 六、总体结论

基于2022年、2023年、2025年北京高考数学三年真题的系统分析，得出以下核心结论：

（1）试卷结构高度稳定：三年均保持"10选择+5填空+6解答"的题型结构，总分150分，解答题85分的分布完全一致。

（2）核心考点固定不变：集合与逻辑、复数、三角函数、立体几何、概率统计、解析几何（椭圆）、导数、数列新定义等模块每年必考，且解答题第18-21题的模块分配高度规律化。

（3）解析几何分值最高：年均24分，主要由椭圆解答题（15分）和双曲线/抛物线小题构成。

（4）新定义题型是压轴特色：连续三年在第21题设置新定义题型，且命题方向从数列向组合扩展，体现对创新思维的重视。
