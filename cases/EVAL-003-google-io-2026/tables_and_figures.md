# EVAL-003 Google I/O 2026 评测稿 · 图表清单

> 这份文件汇总文章里所有的表格和图,以及制作建议。
> 公众号端原生不支持 markdown 表格,**所有表必须先在外部工具渲染后截图为图片**插入。
> 推荐工具:**mdnice.com**(公众号专用 markdown 排版,自动渲染表格)、**飞书/Typora**(直接截图)。

## 整体制图风格建议

- **配色**:Google I/O 主题色系。深蓝 #1A73E8(主色) / 绿 #34A853(✅ 命中) / 黄 #FBBC04(🔶 部分对) / 红 #EA4335(❌/🚫 失败)
- **字号**:公众号端竖屏阅读,**表格字号偏大**,行高松一些。Sarasa Mono / 苹方 / 思源黑体优先
- **冠/亚/季军**用 🥇🥈🥉 emoji 标记
- **正反预测**用 ✅/❌ emoji,**主动校准**用 🔶
- 所有截图建议 **2x 分辨率**(Retina 端清晰),公众号会自动压缩
