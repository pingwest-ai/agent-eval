## 一、与往期的关键差异

1. **多阶段开奖**：不是一次性揭晓，而是 6/27（小组赛）→ 7/3（32强赛完）→ 7/7（16强赛完）→ 7/11（8强赛完）→ 7/15（4强赛完）→ 7/19（决赛+奖项）逐级开奖。**发稿节奏（2026-06-10 拍板）：两大篇** —— 6/11 开幕日预热篇（8 家押注总览 + 共识-分歧矩阵 + 胆量榜，公开发布即押注存证）+ 7/19 后终评篇（综合排名 + 五维明细 + 名场面）；中间节点（如 6/27 小组赛开奖）可发社媒短内容保温，不出正式稿。
2. **判定完全机械化**：球队晋级/夺冠非黑即白，没有 I/O 期"算不算发布"的模糊地带。结果评分争议最小的一期。
3. **对照组天然存在**：博彩市场隐含概率、Opta/Nate Silver 等模型预测全部公开——第 9 选手（外部基准）这期不用找，直接用市场赔率。
4. **Kimi 自家测自家**：Kimi 官方已公开用 300 个 Agent 预测全部 104 场（亮点判断：德国被市场低估、或爆冷夺冠）。我们统一 prompt 下的 Kimi 2.6 Agent 和它官方系统是否一致，是本期最佳看点之一。其他 Agent 检索时可能引用 Kimi 官方预测——审计时标记。

## 二、设计原则（vs Kimi 官方方案）

Kimi 逐场预测 104 场 + 每轮赛前赛后复盘，运营成本高且 8 家横向不可比。本期反其道：**一次性、固定槽位、锦标赛级别**预测——所有 Agent 回答同一组固定问题，归一化在出题时就完成（I/O 期预测项归一化的痛点这期直接消除）。

| P8 | 夺冠概率 Top5 分布（百分比） | 1 | 7/19（按校准度评） |
| P9 | 反共识押注 3 条 | 3 | 分阶段 |

判定规则沿用框架：✅+1.0 / 🔶+0.5 / ❌0 / 🚫-0.5（人工只做逐槽判定，加权由计算完成）。
- P1 头名与第二名互换 → 各记 🔶。
- 预测了**未晋级世界杯的球队** → 🚫（hallucination，本期最硬的诚实度检测）。
- P7 金靴：球员对、进球数 ±1 → ✅；只对人 → 🔶。
- P8 按校准度定性评价（冠军是否在 Top5 内、概率排序合理性），计入过程分 C/E 维度参考，不进结果分。
- **P9 不计入结果分**（2026-06-10 拍板）：单列"胆量榜"，中了高亮、错了公开记录——计分会鼓励押安全牌，毁掉叙事价值。

## 四、权重

纯预测类 + 判定机械化 → **过程 30% / 结果 70%**（框架允许范围内）。
结果分分阶段累计：P1–P6 按槽位汇总计算，P7 决赛日结算。

## 五、过程评分特别规则（时间窗口问题）

开幕在即，信息源审计来不及在 6/11 开赛前做完。规则：
1. 所有 Agent 输出 **6/10–6/11 开赛前**提交并截图/导出存档（时间戳为准）。
2. 审计 6/12–14 进行，**只验证信息源真实性与预测提取，禁止参考任何已赛赛果**。
3. 五维评分 **6/26 前锁定**（首个开奖点之前），存档不得改。
